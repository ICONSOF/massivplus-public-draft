# Jämförelse med andra ramverk - delar

De detaljerade jämförelserna mellan MASSIV+ och etablerade ramverk, grupperade per kategori. Översiktstabellen och den sammanfattande positioneringen ligger i [den överordnade indexsidan](../jamforelse-med-andra-ramverk.md).

- **[Organisationsnivåstandarderna](organisationsstandarder.md)** - GHG Protocol, ISO 14064-1.
- **[Produktnivåstandarderna](produktstandarder.md)** - ISO 14040/14044, ISO 14067, EPD/ISO 14025, PACT, Catena-X.
- **[Infrastruktur- och transaktionslagret](infrastruktur-och-transaktion.md)** - DPP, BEAst.
- **[PCAF](pcaf.md)** - finanssektorns standard för financed emissions.
- **[EU:s rapporteringsarkitektur](eu-rapporteringsarkitektur.md)** - CSRD/ESRS, Voluntary Standard ("VSME").
