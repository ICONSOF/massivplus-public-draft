# Så bidrar du till MASSIV+

Det här repot är öppet. Vem som helst kan läsa, kommentera och föreslå ändringar. Det enda du behöver är ett konto på github.com (gratis).

Det finns tre sätt att bidra, från det lättaste till det mest formella.

## 1. Diskutera - via Discussions

Använd [Discussions](https://github.com/ICONSOF/massivplus-public-draft/discussions) för:

- **Frågor om standarden.** Vad menas med X? Hur tänker ni kring Y?
- **Förslag till nya fördjupningar eller exempel.** Något som saknas?
- **Användningsfall från fält.** Hur ser det här ut i din verksamhet?

Discussions fungerar som ett öppet forum. Ditt inlägg syns för alla och alla kan svara. Du behöver inte föreslå någon konkret textändring - poängen är att resonera.

## 2. Rapportera ett problem - via Issues

Använd [Issues](https://github.com/ICONSOF/massivplus-public-draft/issues) för:

- Sakfel, motsägelser, eller otydligheter i texten.
- Trasiga länkar.
- Förslag på en konkret förbättring av en specifik text.

Skriv en kort beskrivning av vad du sett och var (gärna med länk till stycket). Du behöver inte själv föreslå en ny formulering, även om det går bra.

## 3. Föreslå en konkret textändring - via Pull Request

Om du vill föreslå en exakt ändring:

1. Öppna filen du vill redigera (t.ex. [fordjupningar/bokforingsanalogin.md](fordjupningar/bokforingsanalogin.md)).
2. Klicka på pennikonen ("Edit this file") uppe till höger.
3. Gör ändringen i textfältet.
4. Längst ner: skriv en kort beskrivning av vad du ändrat och varför, välj "Create a new branch" och klicka "Propose changes".
5. På nästa sida: klicka "Create pull request".

Github skapar då en "pull request" - ett konkret förslag som vi kan diskutera i en tråd och sedan slå ihop (eller låta ligga, eller ändra). Du behöver inte ha någon erfarenhet av git eller programmering. Allt sker i webbläsaren.

## Vad händer sedan?

Underhållarna går igenom inlägg, issues och pull requests löpande. Inget blir publikt utan att någon av oss tittat på det - men allt material kommer behandlas öppet och med synlig motivering.
