# Diskutera i Discussions

Använd [Discussions](https://github.com/ICONSOF/massivplus-public-draft/discussions) för att resonera - du behöver inte föreslå någon konkret textändring.

- **Frågor om standarden.** Vad menas med X? Hur tänker ni kring Y?
- **Förslag till nya fördjupningar eller exempel.** Något som saknas?
- **Användningsfall från fält.** Hur ser det här ut i din verksamhet?

Discussions fungerar som ett öppet forum. Ditt inlägg syns för alla och alla kan svara.
